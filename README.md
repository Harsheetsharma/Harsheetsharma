## Highlighted Projects

### OpsFlow
Workflow execution engine designed for distributed task processing.

Core ideas:
- Queue-based job scheduling
- Retry mechanisms
- Worker orchestration
- Fault isolation

Focus: reliability & system resilience.
Repo : https://github.com/harsheetsharma/opsflow

### Paytm-Complete
Digital wallet simulation focusing on backend correctness and financial reliability patterns.

Key engineering aspects:
- Idempotent transaction APIs
- Async processing via queues
- Concurrency-safe balance updates
- Failure recovery patterns

This project explores real-world payment system challenges.
Repo : https://github.com/harsheetsharma/paytm-complete
